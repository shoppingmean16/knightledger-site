From `/steward`: **Prepare work prompt → Copy prompt → run it in the LEGION chat → paste JSON → Import prepared work → review and approve.** The pack includes up to six oldest items. Use the work pack's strict schema and preserve record hashes. Read required private images through authenticated delivery only; do not infer unseen evidence. Return or import results through `/api/operator/import-work` as prepared work only. Do not approve, publish, grant credit, confer titles, contact organizations, spend money or alter settings. If connected tools cannot complete the private bridge, give me the JSON to paste into the Owner desk. Report the prepared items and unresolved reasons, with a link to the approval queue. Keep all member material out of GitHub and public artifacts.

After import:

- Approve exact quests individually or as a list; native publication handles the assigned window.
- Approve evidence recommendations; only then does progress change.
- Check proclamation facts against accepted deeds and approve; native weekly induction grants the title.
- Return inaccurate work with a specific comment. A new work pack carries that feedback.

The AI bridge does not guarantee that an owner starts a chat on schedule. Receipt targets and overdue requests remain visible privately. Publication and weekly induction do not fabricate a successful decision when work or approval is missing.
